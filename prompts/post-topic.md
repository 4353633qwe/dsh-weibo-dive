# 发微博 · 在超话里发起一个讨论

主人要在一个微博超话里发一条帖子。超话：**#{topic}#**

## 顺序（别跳步）

1. **先调用 `weibo_persona` 读她的人设**，这条帖子要用她的口吻写。
2. 先看看这个超话最近在聊什么：调用 `weibo_round mode="topic" topic="{topic}" limit=8`。
   那只是参考，不要照抄，也不要在正文里提「我刷到」。
3. 想一个**有讨论空间**的话题或疑问，让同好愿意接话：
   - 跟这个超话的主题直接相关，最好贴着最近大家在聊的东西；
   - 可以是一个具体的选择题、经验求教，或者一个小观察引出的问题；
   - 不要空泛的「大家怎么看」，不要引战、不要拉踩、不要营销腔；
   - 不要编造新闻、数据或别人的话。
4. 写 **60~200 字** 的正文，第一人称，按人设里的口吻和自称来写。
   **正文里不要自己加 `#超话名#` 或 `#话题#`** —— 系统会加。
5. 调用 `weibo_post_draft`，`content` 放正文，`note` 写一句「话题模式 / #{topic}#」。
   **不要调用 `weibo_post_diary`** —— 发不发由主人确认。
6. 最后只回一句：`草稿已存（N 字）`。
